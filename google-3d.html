拖動旋轉 · 滾輪縮放 · 真 3D 需 Google Maps API Key（已啟用 Map Tiles API）

需要 Google Maps API Key 先睇到真 3D

這就是 Google Earth 同一套 Photorealistic 3D Tiles，路氹每棟樓 1:1。
1. 去 Google Cloud Console → 憑證 建立 API Key
2. 啟用 Map Tiles API
3. 貼上你的 Key（以 AIza 開頭），按「載入真 3D」
Key 只存你瀏覽器 localStorage，唔會上傳。

已有 Key？輸入後自動記住，下次直接入。
無 Key 可先按「OSM 3D 示意」睇可賽車馬路（非相片級）。
